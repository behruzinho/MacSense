# Проверка MacSense 0.2.0 перед релизом

Чек-лист для проверки публичного выпуска 0.2.0 и последующих исправлений. Начните с `dist/MacSense.app`; при нескольких копиях закройте старую, чтобы не сравнивать разные версии. Версия указана внизу окна и в «О MacSense».

- [ ] **Обзор:** прежнее оформление и живые показатели сохранены. Верхняя карточка показывает чип, память, загрузочный диск, macOS/сборку и скрытый серийный номер. Проверьте кнопку глаза; номер не попадает в экспорт.
- [ ] **Мониторинг:** выключите/включите одну панель, поменяйте порядок, проверьте единую колонку и метрику строки меню. После перезапуска настройки сохраняются.
- [ ] **Накопители:** раскройте раздел → контейнер APFS → тома. В «Статистике» показатели меняются при работе с файлами. Общий SMART может быть доступен без подробных NVMe-атрибутов.
- [ ] **Тест скорости:** выберите папку на нужном диске, начните тест и попробуйте отмену. Тест создаёт только собственный временный файл. Данные пользователя не перезаписываются.
- [ ] **Приложения:** дождитесь сканирования, найдите приложение, раскройте группы, выберите один файл и проверьте частичную галочку/сумму. Нажмите «Отмена», чтобы очистить выбор. Для первого знакомства удалять приложения не требуется.
- [ ] **Очистка:** проверьте категории, Finder, знак ≥ у частичных размеров и отмену сканирования. Не выбирайте личные загрузки/архивы, которые нужны. У симуляторов и системных журналов выбор недоступен.
- [ ] **Автозагрузка:** проверьте различие «разрешён запуск» и «загружен». Переключение пользовательского агента требует подтверждения; системные службы только просматриваются. Не меняйте незнакомые агенты для проверки интерфейса.
- [ ] **Языки:** русский, английский, китайский, испанский и немецкий; особенно новые экраны и подтверждения.

## Проверено автоматически и на этом Mac

22 автоматические проверки: счётчики CPU/сети, SMC, границы путей и symlink, точное соответствие bundle ID, APFS/SMART, временный файл бенчмарка и отмена, настройки панелей, формат launchctl, пять языков. Интерфейс проверен на Apple Silicon; Intel отдельно не проверен.

При проверке разработчиком файлы пользователя не удалялись и службы не переключались. Тесты бенчмарка выполняются в отдельном временном каталоге, созданном тестом.

Выпуск 0.2.0 распространяется с подписью Developer ID, оформленным DMG, ZIP и SHA-256. Notarization Apple завершена: приложение и DMG приняты без замечаний, подтверждения прикреплены и проверены, Gatekeeper принимает выпуск как Notarized Developer ID. Приложение внутри ZIP и DMG проверено отдельно. Пользовательские проверки выше остаются отдельным чек-листом и не означают, что удаление файлов или переключение служб было выполнено разработчиком.
