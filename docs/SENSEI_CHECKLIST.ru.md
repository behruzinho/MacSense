# MacSense: сравнение с 24 скриншотами Sensei

Сравнение сделано по присланным экранам, а не по внутреннему устройству Sensei. Сохраняем текущий интерфейс MacSense, живые показатели, пять языков, экспорт, меню macOS и благодарность behruzinho. Скриншоты с личными аппаратными идентификаторами в репозиторий не включаем.

Обозначения: [x] реализовано; [ ] требуется работа. «Частично» означает работающую возможность с указанным ограничением.

## Обзор и оборудование (скриншоты 7, 9, 13, 14, 17)

- [x] CPU: общая/пользовательская/системная нагрузка, ядра, история, процессы.
- [x] RAM: использование, приложения, wired, сжатие, кэш, swap, давление памяти, процессы.
- [x] GPU: реальная загрузка IOAccelerator, ядра, история, доступные температуры.
- [x] Батарея: заряд, питание, время, расчёт здоровья, циклы, ёмкости, ток, напряжение, мощность, температура.
- [x] Охлаждение: реальные SMC-датчики, RPM, аппаратные min/max, история.
- [x] Сеть: входящий/исходящий трафик, скорость, история.
- [ ] Имя компьютера, сборка ОС, аппаратный серийный номер с раскрытием по запросу.
- [ ] Производитель/серийный номер/дата батареи, сведения Metal и память GPU.
- [ ] Достоверные дата выпуска, дата производства и завод Mac: требуется база моделей; современные случайные серийные номера не декодируем предположениями.
- [ ] Дополнительная группировка датчиков корпуса, питания, Wi-Fi и платы.

## Накопители (скриншоты 10–12, 16, 18)

- [x] Объём, свободное/занятое место, файловая система, модель, базовый SMART и TRIM.
- [ ] Физические диски, интерфейс, block size, состояние и дерево APFS/разделов.
- [ ] Живая статистика чтения/записи дисков.
- [ ] Запускаемый пользователем тест скорости с ограниченным временным файлом и отменой.
- [ ] Подробные NVMe SMART: износ, температура, записанные байты, часы и ошибки. Нужен работающий провайдер этих данных; базовый SMART не превращаем в выдуманный процент здоровья.
