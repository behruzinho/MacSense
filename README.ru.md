# MacSense

Нативный монитор системы macOS: процессор, память, графика, батарея, диски, сеть, температуры и вентиляторы в одном приложении.

Автор: **[behruzinho](https://github.com/behruzinho)** · [English](README.md) · [Скачать](https://github.com/behruzinho/MacSense/releases)

**Сейчас 0.2.0 — сборка для проверки, публичный релиз ещё не опубликован.** Изменения доступны в `main`; готовые файлы будут опубликованы после ручной проверки.

## Установка

1. Скачайте **DMG нужной версии** на странице [Releases](https://github.com/behruzinho/MacSense/releases).
2. Откройте DMG и перетащите **MacSense.app** в **Applications / Программы**.
3. Запустите приложение из «Программ».

Требуется **macOS 14+**. Готовая сборка предназначена для **Apple Silicon (arm64)**. Также доступны ZIP с приложением и контрольные суммы SHA-256. Для Intel можно собрать исходники; проверенной Intel-сборки в первом релизе нет.

Это первый публичный предварительный выпуск. Поддерживаются подпись Developer ID и notarization Apple; статус конкретной сборки указан в её релизе. Сохраняйте Gatekeeper включённым. Если macOS ограничивает запуск, ознакомьтесь с [инструкцией Apple](https://support.apple.com/102445).

## Возможности

- Общая панель показателей с графиками и характеристиками Mac.
- Интервальная загрузка CPU, каждого ядра и активные процессы.
- Физическая память, кэш, сжатие, нагрузка на память и подкачка.
- Заряд, оценка состояния, циклы, ёмкость, температура и электрические параметры батареи.
- Чтение оборотов вентиляторов и температур через AppleSMC.
- Параметры GPU и доступные данные загрузки.
- Занятое пространство томов, доступные сведения NVMe, S.M.A.R.T. и TRIM.
- Скорость приёма и отправки данных через сеть.
- Список приложений и связанных файлов по точному идентификатору.
- Сканирование пользовательских кэшей и журналов.
- Просмотр конфигураций автозагрузки и переход к объектам входа macOS.
- Настраиваемые панели и показатель строки меню, темы, интервал обновления, пауза и экспорт отчёта.

## Языки

В **Настройки → Язык и оформление** можно выбрать русский, английский, упрощённый китайский, испанский, немецкий или язык системы. Переключение работает без перезапуска. Переведены интерфейс, диалоги, отчёты и единицы; системные меню macOS могут следовать языку системы.

## Приватность и удаление файлов

Данные обрабатываются локально. Приложение не отправляет аппаратные показатели, процессы и списки файлов в интернет. Ссылки на автора и поддержку открываются в браузере по нажатию.

Очистка проверяет пользовательский кэш/журналы, DerivedData, архивы Xcode, DeviceSupport, Загрузки (крупные объекты от 500 МБ, DMG и установщики), Mail Downloads, симуляторы и `/Library/Logs`. Симуляторы и системные журналы доступны только для просмотра. Личные файлы и архивы сборок не считаются мусором автоматически.

Список приложений включает `.app` в `/Applications` и `~/Applications` до трёх уровней вложенности. Связанные файлы определяются по точному bundle identifier, включая Containers и Application Scripts. Общие Group Containers исключены. Можно выбирать отдельные файлы, группы и несколько приложений; есть прогресс и отмена сканирования. Серийные номера скрыты до раскрытия и исключены из отчётов.

Файлы перемещаются в Корзину только после выбора и подтверждения. Автоматической очистки нет. Символ **≥** означает, что размер каталога подсчитан частично из-за ограничения времени. Защищённые папки могут быть недоступны.

## Ограничения первого выпуска

Датчики, GPU, NVMe, S.M.A.R.T. и TRIM зависят от модели и macOS. Недоступные показатели отмечены явно. Неизвестные датчики показывают SMC-ключ; температура CPU — среднее по найденной группе процессорных датчиков.

Охлаждением управляет macOS. Ручное управление вентиляторами, изменение TRIM, привилегированный помощник и автоматические обновления не включены. Пользовательские агенты переключаются с подтверждением: меняется разрешение будущего запуска, уже загруженный процесс не завершается. Состояние launchd и автозапуск самого MacSense отображаются отдельно. CPU процессов берётся из `ps`, память — RSS.

Накопители: физические диски, APFS/разделы, живая статистика I/O и тест скорости на диске выбранной папки. Тест создаёт один уникальный временный файл 64–1024 МиБ, отключает файловый кэш и удаляет файл после завершения или отмены.

Подробный NVMe SMART доступен через отдельно установленный `smartctl` в `/opt/homebrew/bin` или `/usr/local/bin`, если разрешено чтение устройства. MacSense не устанавливает его и не вызывает `sudo`. Без этого источника показывается общий SMART macOS, без выдуманного процента здоровья SSD.

В «Мониторинге» можно выбирать и переставлять панели, включить единую колонку и выбрать показатель строки меню. Название/сборка ОС, загрузочный диск, чип, память и серийный номер находятся в верхней карточке Mac. Диагональ встроенного дисплея приблизительно оценивается по Core Graphics, если доступны подходящие размеры.

## Сборка

Понадобятся Xcode или Command Line Tools со **Swift 5.10+**.

```sh
git clone https://github.com/behruzinho/MacSense.git
cd MacSense
./script/build_and_run.sh
```

Приложение появится в `dist/MacSense.app`.

```sh
swift test
./script/build_and_run.sh --build
./script/build_and_run.sh --verify
./script/package_release.sh
```

Последняя команда создаёт оптимизированную сборку, DMG, ZIP и SHA-256 в `dist/releases/`. Параметр `MACSENSE_ARCH` позволяет выбрать `arm64` или `x86_64`; сборку нужно отдельно проверить на целевом оборудовании.

## Подпись и notarization

С сертификатом Developer ID Application и его закрытым ключом:

```sh
MACSENSE_SIGN_IDENTITY='ваш Developer ID Application' ./script/package_release.sh
./script/configure_notary.sh MacSense-Notary
./script/notarize_release.sh MacSense-Notary
```

Первую настройку выполните самостоятельно в терминале: Apple ID и пароль приложения сохранятся в Связке ключей. Не помещайте их в Git и не отправляйте в чат. Скрипт notarization отправляет сборку на проверку Apple, прикрепляет билеты к приложению и DMG, проверяет их и обновляет контрольные суммы. После проверки не пересобирайте и не переподписывайте выпуск без новой notarization.
